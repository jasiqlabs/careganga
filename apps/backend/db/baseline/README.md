# CareGanga V1 baseline

**Single schema artifact:** schema.sql (PostgreSQL 17), manifest.json (SHA-256 + actual 311 historical ledger hashes). This is the final logical schema extracted from an isolated migrated database, not concatenated migration scripts. All 12 logical catalog categories matched a second database recreated from exported statements; exact committed full SQL blob also restored atomically on a third initially empty QA database. See catalog-verification.json and catalog-atomic-verification.json. 353 UUID defaults explicitly reference pg_catalog.gen_random_uuid so the pgcrypto extension cannot change function binding. No accounts, patients, donors, finance or other operational rows exported; only historical ledger. Root provisioning and approved CMS publication remain separate first-release operations. Do not overwrite a published baseline.

Catalog comparison excludes provider physical metadata and environment-specific ownership/privileges. Actual Node CLI, role/Hostinger packaging qualification, restart/upgrade, backup and all original business QA remain required. Historical source remains frozen in ../migrations for old source guards; no replay on deployment. New upgrades only in ../upgrades. See [Hostinger setup](../../../../docs/deployment/hostinger-greenfield-database.md).
