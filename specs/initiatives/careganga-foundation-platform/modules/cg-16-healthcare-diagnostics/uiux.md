## 3. Screen and human-state blueprint

**H09 US-001:** authorized Foundation master editor selects category/sample type, enters unique test code/name/description, creates real package from included original active tests, maps a current CG-14 verified lab center and selects effective start/end price version (integer minor amounts, no overlaps), shows approved base/patient commercial price and a real published center discount only if own partner source validates. Show current pricing status `DRAFT/PENDING_APPROVAL/APPROVED/PUBLISHED/EXPIRED/INACTIVE`, not example counts. Duplicate creates a new code/revision with explicit new name and no shadow patient test. Import remains time-scoped gated, export scoped and private-rate protected; safe Cancel/Save and undo/pending/unknown states. Setting a price for inactive/unmapped/foreign center fails. When all four ERP flags OFF, **nothing on H09 requires H10 order or specimen**, no "Create Lab Booking" shortcut.

**Actual financial boundary in all screens:** H09 accepted partner commercial test price is CG-16 metadata, not a receipt; H10 internal ordered test is not proof of paid status. **CG-17** alone owns genuine center-collected payment, real Foundation contribution and center settlement; **CG-09** alone owns authorized Foundation journal postings. Hide paid/discount-subsidy/contribution/settled badges when no original CG-17 confirmed source, and never create CG-09 posting from Save Test, Create Lab Order, Release Result or Enquire.\n\n**H08 US-003/004:** same original Lab Details selected right-pane shows CG-14's genuine provider/license/info, CG-16's current tests/prices, no healthcare center clone. Lab specific enquiry from actual published test/center is just source-safe CG-14 public contact and optional original CG-19 question, with rate-limit, safe no-price disclosure when center rate expired, clear not booking/no payment text. User selecting a different branch sees that branch's actual mapped tests and price, not one parent center sample. Public native and Web search by test/category/price/center and real source return. No patient test order, sample barcode or private phone leaked.

**H10 US-002 only ERP enabled:** staff authenticated CG-01/CG-14 center, selects verified CG-15 consented patient within permitted care intake and actual US-001 active test/package revision. Confirm real order with `AMOUNT_DUE` (not "Paid") unless CG-17 true verified source says otherwise. Individual sample collection and specimen label, chain-of-custody receiver/transfer/history/time, recorded process result uploaded through CG-19, mandatory genuine authorized licensed specialist review, then separately signed **RELEASED** report. Show distinct `ORDER_CREATED/COLLECTION_PENDING/COLLECTED/PROCESSING/RESULT_READY/AWAITING_PROFESSIONAL_REVIEW/REVIEW_REJECTED/RELEASED/CORRECTED` and separate CG-19 email/SMS/WhatsApp `SEND_PENDING/SENT/DELIVERED/FAILED/UNKNOWN`. A **report uploaded** is not "Released"; a **released PDF** is not automatically "Delivered". "Resend" only when genuine previously released file and configured outbound provider. Cross-center patient/clinician cannot view without actual consent/care-purpose; forbidden shows safe result without existence leak. On ERP OFF, no creation/action/status/read of private operational queue, but authenticated own lawful released report remains accessible via protected CG-19.

**H08/H10 US-005 equipment:** true center-scoped equipment code/type/calibration/maintenance due/readiness, actual CG-19 protected quality documents/reviewer; `READY/MAINTENANCE_DUE/OUT_OF_SERVICE/REVIEW_PENDING`. Never show supplier item balances, actual pharmacy batch or Foundation CG-12 store; never infer an official accreditation from screenshot image. Support applicable handheld evidence capture only if authorized, but no required default Internal Android analyzer screen.

**Global errors and privacy:** `ERP_DISABLED/NO_CENTER_GRANT/CLINICAL_PROVIDER_UNVERIFIED/NO_PATIENT_CONSENT/STALE_PRICE/INVALID_SAMPLE/NEEDS_PROFESSIONAL_REVIEW/WRONG_SCOPE/UNKNOWN_WRITE_STATUS/NO_APPROVED_LAB/NO_PUBLISHED_TEST` with readable user feedback; accurate empty vs Loading vs report not released vs service disabled. Hard backend authorization for list/selector/detail/update/export/file/QR. No searchable public patient lab name, clinical result/receipt URL, technician private phone, bank details or patient symptom in CDN/SSR/mobile logs. Human accessible color+icon+label, error return focus, keyboard/large text, Android TalkBack/back and reduced motion.
