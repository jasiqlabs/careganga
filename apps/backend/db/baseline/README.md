# First-release baseline (generated, not hand-written)

The required release artifacts are `schema.sql` and `manifest.json`. They are **not yet generated** at this source checkpoint. The existing SQL migrations remain the authoritative inputs. Do not concatenate files or invent a schema. Generate against two empty, isolated local PostgreSQL databases of the intended production major version (recommended 17). Both must be named `careganga_baseline_*`; never use any shared or production DB.

See [Hostinger setup](../../../../docs/deployment/hostinger-greenfield-database.md). Generation runs the historical migration chain on the first disposable DB, restores one consolidated dump on the second, compares schema and complete dump, checks all migration checksums, and only then writes the artifact. Independently inspect the generated SQL, default records, role privileges and business integrity. Commit the two artifacts before release; they are not to contain business/test data or secrets. Once released, never regenerate/replace this baseline without a separately reviewed future baseline policy. Retain the historical SQL files for existing test/source checks and ledger compatibility; none is executed by db:init.
